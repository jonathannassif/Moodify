Moodify 🌈

A mindful web experience for exploring emotions through design.

Moodify is a front-end project that turns emotions into interactive, visually immersive web pages.
Each “mood” page — like Angry, Anxious, Lost, Stressed, Happy, or Sad — is thoughtfully styled to capture the emotional tone through color, animation, and gentle interaction.

✨ Features

🎭 Emotion-Specific Design: Each mood has its own palette, typography, and motion style to evoke the right feeling.

🧘 Mindful Interactions: Buttons, quotes, and reflection prompts guide the user toward calmness or clarity.

🌤️ Minimalistic UI: Focused on simplicity and emotional resonance — no visual clutter, just the essence of the feeling.

💾 Personal Touch: Reflections can be saved locally to track emotional insights.

📱 Responsive Layout: Works smoothly across devices.

🧩 Tech Stack

HTML5 for structure

CSS3 (Flexbox & animations) for visual mood expression

JavaScript (Vanilla) for interactive transitions and user engagement

🎨 Design Philosophy

Moodify blends emotional psychology with frontend design.
Instead of overwhelming users with content, it provides quiet, purposeful interfaces that reflect and soothe each emotion — creating a calm, introspective digital space.
