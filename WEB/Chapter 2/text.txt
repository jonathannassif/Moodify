Here’s a curated cheat-pack just for your web dev journey (front-end → full-stack path):

⌨️ VS Code Shortcuts (Windows/Linux, Mac in brackets)

Ctrl + P (Cmd + P) → Quick open file by name

Ctrl + Shift + P (Cmd + Shift + P) → Command palette (do anything)

Alt + ↑ / ↓ (Option + ↑ / ↓) → Move line up/down

Alt + Shift + ↑ / ↓ (Option + Shift + ↑ / ↓) → Duplicate line

Ctrl + / (Cmd + /) → Comment/uncomment line

Ctrl + D (Cmd + D) → Select next matching word (multi-cursor)

Ctrl + Shift + L (Cmd + Shift + L) → Select all matching words

Ctrl + B (Cmd + B) → Toggle sidebar

**Ctrl + ** (Cmd + ) → Open terminal in VS Code

Emmet cheat → div.container>ul>li*5 → expands into HTML structure instantly

🚀 VS Code Extensions (must-haves)

Live Server → auto-refresh browser on save

Prettier → auto-format code

Auto Rename Tag → rename <div> automatically renames </div>

Path Intellisense → autocomplete file paths

CSS Peek → jump from HTML class → CSS definition

Error Lens → highlights errors inline

Icons (Material Icon Theme) → file icons for easy navigation

🌍 Browser Dev Tools (Chrome/Edge)

F12 or Ctrl+Shift+I → Open DevTools

Ctrl+Shift+C → Pick/inspect element

Console Tab → test JS quickly

Network Tab → see API requests

Application Tab → see localStorage, cookies

⚡ Web Dev "Cheatcode" Tools

CodeSandbox / StackBlitz → Instant online dev environment

Tailwind Play → Tailwind CSS playground

Canva + Figma → for quick UI mockups

Responsively App → test your site on multiple screen sizes at once

GitHub Copilot (if free trial) → AI autocomplete for code

🧠 Learning Efficiency

Anki → make flashcards for concepts (like you started)

LeetCode / CodeWars → practice JS problems

Excalidraw → visualize ideas (great for planning projects)

Ray.so → turn code snippets into aesthetic images for sharing
